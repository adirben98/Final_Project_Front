# Bookify - AI Children's Books


A web application that generates personalized children's books using AI. This frontend connects to a backend API that handles the AI generation and book creation.

## Features

- 🎨 Create custom children's books with AI-generated content
- 📖 Interactive book preview and reading interface
- 🔐 User authentication and book saving functionality

## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (v16 or higher)
- npm (v8 or higher)
- The [backend server](https://github.com/adirben98/Final_Project_Back) running locally

## Installation

1. **Clone the backend repository first** (required for full functionality):
   ```bash
   git clone https://github.com/your-username/backend-repo.git
   cd backend-repo
   npm install
   npm start
   ```
2. **Clone this frontend repository**:
   ```
   git clone https://github.com/your-username/Final_Project_Frontend.git
   cd Final_Project_Frontend
   ```
3. **Install dependencies**:
   ```
   npm i
   ```
4. **Run the development server**:
   ```
   npm run dev
   ```
The application should now be running on http://localhost:3000.
